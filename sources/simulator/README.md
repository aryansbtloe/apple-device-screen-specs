# Xcode Simulator measurements (2026-10-27)

- Mac: Xcode 27.1 (27A9275). Runtimes: iOS 27.0 (24A434) for 62 device types and iOS 27.1 (24A94425), which supports only iPhone Duo. No watchOS or visionOS runtime is installed.
- `raw/<device-type>.json`: output of `scripts/simulator/Measure.swift`, a scene-based UIKit app built with `swiftc` and installed on throwaway `ssm-*` simulators (at most 2 booted at once) by `scripts/simulator/run_all.sh`. Each file has UIScreen bounds, nativeBounds, scale, nativeScale, UIScreen.screens and connected scenes, and the key-window safeAreaInsets, status bar and home indicator in portrait, landscapeLeft and landscapeRight (rotated via `requestGeometryUpdate`). It also has the private `_displayCornerRadius` (UNOFFICIAL).
- `status.tsv`: one line per iPhone/iPad/iPod device type: OK, or UNSUPPORTED (not in either iOS 27 runtime's supportedDeviceTypes).
- `devicetype_profiles.json`: static data from every `.simdevicetype` bundle. In Xcode 27.1, `profile.plist` has no `mainScreen*` keys. The screen data sits in the sibling `capabilities.plist`: `ScreenDimensionsCapability`, `displays[]` (width, height, canvasWidth/Height, scale, hdpi/vdpi, cornerRadiusUL/UR/LL/LR) and `DeviceCornerRadius`.
- `chrome.json`: the `/Library/Developer/DeviceKit/Chrome/*.devicechrome/Contents/Resources/chrome.json` outlines. `simpleOutsideBorder.cornerRadiusX/Y` describes the bezel artwork, not the display, so it is not used.
- `experiments/`: the iPad (10th gen) rerun with `UIRequiresFullScreen` and a 6 s settle time. Not merged (see reports/conflicts.md #16).
- `measurements.json` and `summary.csv` are generated by `scripts/import_simulator.py`. `scripts/build_dataset.py` merges `measurements.json`.

Rebuild: `python3 scripts/import_simulator.py && npm run build && npm run validate`.
